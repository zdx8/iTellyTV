和 macOS 版的区别

iTellyTV 继承了 iTelly-macOS 的设计、错误恢复、协议支持，但用 Media3 / ExoPlayer 替代了 libVLC 内核——

功能

订阅 + 频道列表

远程 m3u / m3u8 订阅、本地文件导入、单条流直连。CCTV 在前、湖系优先的自然排序。

播放器全屏

SurfaceView 长期存活、永不替换。切频道只换 MediaItem，0 ms 重建延迟。

错误恢复

1s/2s/4s 退避重连，最多 3 次。15s 无进度看门狗。连续失败自动跳下一频道；全部失败显示"服务器挂了"。

D-pad 完整适配

↑/↓ 切台，← 召唤频道列表抽屉，OK 选台，Back 二级返回，数字键直接跳 N 号频道。

收藏 / 长按菜单

长按 OK 在某频道：加入收藏 / 取消收藏。★ 标记左侧出现。

Room + Flow 数据层

Activity 重建不丢数据。Flow 自动响应数据库变化。100 个 unit test 覆盖核心逻辑。

系统媒体控制

MediaSession + 前台服务，Android TV 的系统媒体通知与遥控器播放/暂停键在后台也能用。

签名 release 构建

GitHub Actions 从仓库 secrets 读 keystore，产出可直接 adb install 的已签名 APK，附 SHA-256 校验和。

安装

到 Releases 下载最新的 iTellyTV-v1.2.0-release.apk（**已签名**，4.4 MB），用 adb 装到 Android TV：

adb install -r iTellyTV-v1.2.0-release.apk
adb shell am start -n com.example.itellytv/.ui.MainActivity

首次启动会提示"是否允许安装未知应用"——去 设置 → 安全 → 允许此来源。

校验下载完整性：

shasum -a 256 --check iTellyTV-v1.2.0-release.apk.sha256

订阅源

iTellyTV 默认加载您 home 网络上的 IPTV 订阅：

http://10.0.0.51:1905/interface.m3u?profile=keren

想换订阅？长按主页右上角的 ⟳ Reload 按钮 → 输入新的 m3u URL → Load。

架构亮点（继承自 macOS）

iTelly-macOS README 列了"5 个值得记录的实现要点"——iTellyTV 全部继承：

  1. DataSource 工厂包装：DefaultHttpDataSource.Factory 在 ExoPlayer.Builder().build() 之前一次性建好（含 #EXTVLCOPT headers + 超时 + User-Agent）。
  2. 重连退避 + 上限：1s/2s/4s，最多 3 次——修复 macOS "自动重连永不停"那个 bug。
  3. 音量范围一致：Media3 volume 0.0f-1.0f，避免 macOS 的"一处用 0-1、另一处用 0-100"陷阱。
  4. 渲染视图长期存活：视频 SurfaceView 永不替换（macOS 的 VLCCAOpenGLLayer 教训）。
  5. LoadControl 设完再 build：LiveConfig / BufferDurations 在 Builder 之前全部设好。

最新版本 v1.2.0

  • 全量代码审计修复 — 修掉 19 个 severe / high / medium 缺陷，包括：MediaSession 绑定被 onBind 返回 null 打断、播放页返回后主页频道列表空白、抽屉实际铺满全屏而不是 30%、重连计数永不复位导致无限重连。
  • 订阅刷新不再丢数据 — 刷新改为原地合并（按 URL 对账：新增 / 更新 / 删除），不再重建整张表。此前每次冷启动刷新都会给所有频道换新主键，静默清空收藏和最近播放；重复订阅同一个源还会不断新建播放列表。现已修复。
  • 抽屉交互修正 — 真实 30% 宽（右 70% 继续播放视频）、上下键首尾环绕、按 OK 选台后立即消失、无操作 3s 才自动消失。
  • OK 键更可靠 — 在 dispatchKeyEvent 层处理，兼容只发 ACTION_UP 的遥控器；长按方向键才连发。
  • 签名 release APK — GitHub Actions 从仓库 secrets 解码 keystore，产出可直接安装的已签名 APK（APK Signature Scheme v1 + v2 均通过 apksigner verify）。
  • R8 压缩 — release 构建启用 minify + resource shrink，APK 从 11.7 MB 降到 4.4 MB（-62%），100 个 unit test 全绿、lintDebug 0 error。
  • SHA-256 校验和 — 每个 APK 附件都带 .sha256 文件。

历史版本见 Releases。v1.0.0 是首个公开版本；v1.1.0 加入签名构建与 R8 压缩。
